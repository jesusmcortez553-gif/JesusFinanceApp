# Finanzas Personal

App de control de gastos e ingresos personales construida con React.

## Funcionalidades
- 📊 Dashboard con resumen visual
- ➕ Registrar ingresos y gastos
- 📋 Historial con edición y eliminación
- 🎯 Metas de ahorro con progreso
- 📈 Gráficos por mes y categoría
- 🔍 Filtro por mes

## Tecnologías
- React 18
- Recharts (gráficos)
- Lucide React (iconos)

## Instalación local
```bash
npm install
npm start
```
